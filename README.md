# Sistema de Citas Médicas - Arquitectura en Capas

Proyecto desarrollado para la materia Arquitectura de Software.

## Modelo de Arquitectura
Arquitectura en Capas (N-Capas)

## Lenguaje de Descripción
UML

## Estructura

- presentation → Interfaz de usuario
- business → Lógica del sistema
- data → Acceso a datos

## Tecnologías
- HTML5
- JavaScript
- Git
- GitHub

## Descripción de la Arquitectura Seleccionada

Se seleccionó la Arquitectura en Capas (N-Capas) debido a que permite organizar el sistema en niveles claramente definidos, facilitando el mantenimiento, la escalabilidad y la separación de responsabilidades.

El sistema se divide en:

- Capa de Presentación: Encargada de la interfaz gráfica y la interacción con el usuario.
- Capa de Lógica de Negocio: Procesa las reglas del sistema y valida la información.
- Capa de Acceso a Datos: Gestiona el almacenamiento y recuperación de datos.

Esta arquitectura mejora la organización del código y permite futuras ampliaciones sin afectar otras capas.

## Requerimientos de las Tecnologías Utilizadas

Para ejecutar el proyecto se requiere:

- Navegador web moderno (Chrome, Edge o Firefox).
- Soporte para HTML5 y JavaScript.
- Editor de código como Visual Studio Code.
- Git instalado para control de versiones.
- Cuenta en GitHub para almacenamiento del repositorio.

No se requiere servidor externo ya que el proyecto funciona como aplicación web básica.
